# Priyanshi Soni — Software Engineer Portfolio

A responsive portfolio highlighting backend engineering, AI application development, voice-agent integrations, cloud workflows, and automation.

## Run locally

1. Extract the ZIP.
2. Open `index.html` in a browser, or serve the folder with any static web server.

## Customize

- Update profile links and contact details in `index.html`.
- Update experience, project descriptions, skills, and education directly in `index.html`.
- Adjust colors, typography, spacing, and responsive behavior in `css/style.css`.
- The personal projects section is intentionally hidden for now.
